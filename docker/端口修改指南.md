# Dify 端口冲突解决方案

## 问题描述
线上环境部署时出现端口冲突错误：
```
Error response from daemon: driver failed programming external connectivity on endpoint docker-nginx-1: Error starting userland proxy: listen tcp4 0.0.0.0:80: bind: address already in use
```

## 解决方案

### 1. 已修改的端口配置
我们已经在 `docker/.env` 文件中修改了以下端口：

#### 主要冲突端口（已修改）
- **Nginx HTTP端口**: 80 → 8080
- **Nginx HTTPS端口**: 443 → 8443

#### 其他可能冲突的端口（已配置）
- **Weaviate**: 8080
- **OceanBase**: 2881
- **OpenGauss**: 6600
- **MyScale**: 8123
- **MatrixOne**: 6001
- **Elasticsearch**: 9200
- **Kibana**: 5601

### 2. 部署步骤

#### 步骤1: 停止现有服务
```bash
cd /path/to/dify/docker
docker-compose down
```

#### 步骤2: 使用新的端口配置
```bash
# 确保在docker目录下
cd /path/to/dify/docker

# 启动服务（使用.env文件中的端口配置）
docker-compose up -d
```

#### 步骤3: 验证服务状态
```bash
# 检查容器状态
docker-compose ps

# 检查端口监听情况
netstat -tlnp | grep -E ':(8080|8443|5432|6379)'
```

### 3. 访问地址

修改端口后，访问地址变为：
- **Web界面**: http://your-server-ip:8080
- **HTTPS界面**: https://your-server-ip:8443

### 4. 如果需要修改其他端口

如果还有其他端口冲突，可以编辑 `docker/.env` 文件：

```bash
# 编辑环境变量文件
vim docker/.env

# 修改相应的端口配置，例如：
# EXPOSE_NGINX_PORT=8080  # 可以改为其他端口
# OCEANBASE_VECTOR_PORT=2881  # 可以改为其他端口
```

### 5. 注意事项

1. **防火墙配置**: 确保新端口在防火墙中开放
2. **反向代理**: 如果使用Nginx反向代理，需要更新配置
3. **负载均衡**: 如果使用负载均衡器，需要更新后端端口配置

### 6. 故障排除

如果仍然有端口冲突：

1. **检查端口占用**:
   ```bash
   netstat -tlnp | grep :80
   netstat -tlnp | grep :443
   ```

2. **查看Docker容器状态**:
   ```bash
   docker ps -a
   ```

3. **查看Docker日志**:
   ```bash
   docker-compose logs nginx
   ```

### 7. 恢复默认端口（如果需要）

如果需要恢复默认端口，可以：
1. 删除或重命名 `docker/.env` 文件
2. 重新启动服务：`docker-compose up -d`
