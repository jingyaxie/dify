# Dify 管理员账号设置指南

## 概述
Dify 没有预设的默认管理员账号，需要通过初始化流程创建第一个管理员账号。

## 初始化流程

### 1. 环境准备
确保已经按照之前的端口修改指南配置好环境：
- 修改了 nginx 端口（80→8080, 443→8443）
- 创建了 `.env` 文件
- 设置了初始化密码

### 2. 启动服务
```bash
cd /path/to/dify/docker
docker-compose up -d
```

### 3. 访问初始化页面
在浏览器中访问：
```
http://your-server-ip:8080/init
```

### 4. 输入初始化密码
在初始化页面输入：
- **初始化密码**: `dify123456`

### 5. 创建管理员账号
验证成功后，跳转到安装页面，填写：
- **邮箱地址**: 管理员邮箱（如：admin@yourcompany.com）
- **用户名**: 管理员用户名（如：admin）
- **密码**: 管理员密码（建议使用强密码）

### 6. 完成设置
点击"创建账户"完成管理员账号设置。

## 登录系统

设置完成后，使用创建的管理员账号登录：
- **登录地址**: `http://your-server-ip:8080/signin`
- **邮箱**: 您设置的管理员邮箱
- **密码**: 您设置的管理员密码

## 重要提醒

### 安全建议
1. **修改初始化密码**: 首次登录后，建议修改初始化密码
2. **使用强密码**: 管理员密码应包含字母、数字和特殊字符
3. **定期更换密码**: 建议定期更换管理员密码

### 环境变量配置
如果需要修改初始化密码，编辑 `.env` 文件：
```bash
# 修改初始化密码
INIT_PASSWORD=your_new_init_password
```

### 故障排除

#### 问题1: 无法访问初始化页面
- 检查服务是否正常启动：`docker-compose ps`
- 检查端口是否正确：`netstat -tlnp | grep 8080`
- 检查防火墙设置

#### 问题2: 初始化密码验证失败
- 确认 `.env` 文件中的 `INIT_PASSWORD` 设置正确
- 重启服务：`docker-compose restart`

#### 问题3: 创建管理员账号失败
- 检查邮箱格式是否正确
- 确认密码符合要求（至少8位，包含字母和数字）
- 查看日志：`docker-compose logs api`
